## Selected public projects

### [Messenger Better Search](https://github.com/gkk-dev-ops/messenger-better-search)

A privacy-first browser extension that imports a user's own Meta message export and turns it into a local, searchable archive.

- local-first: conversations stay in IndexedDB and require no project backend
- incremental imports with deduplication
- full-text search, date filters, grouping, and conversation context
- optional bring-your-own-key AI integrations
- tested with unit/integration tests and Playwright E2E

### [clck](https://github.com/gkk-dev-ops/clck)

A responsive, cross-platform terminal countdown alarm written in Rust.

- natural duration formats and guided interactive setup
- adaptive ASCII display, sounds, and desktop notifications
- macOS and Linux support, with best-effort Windows support
- distributed through [crates.io](https://crates.io/crates/clck) and GitHub Releases
- [documentation](https://gkk-dev-ops.github.io/clck/)

### [PaperKey](https://github.com/gkk-dev-ops/PaperKey)

A privacy-first PWA for preparing sensitive strings for print, backup, and verbal recovery.

- exact, character-by-character, and phonetic representations
- all processing and history remain in the browser
- configurable expiry and purge controls
- offline support with no backend, accounts, analytics, or third-party scripts

### [Nasze Miasteczko / apfel-stadt](https://github.com/gkk-dev-ops/apfel-stadt)

An experimental city-building game prototype for macOS and iPhone.

- Unity client with building, economy, goals, save files, and device features
- TypeScript synchronization API
- GCP infrastructure described with Terraform
- local-first play with optional cross-device cloud synchronization

### [rfc-cli](https://github.com/gkk-dev-ops/rfc-cli)

A small Python command-line tool for reading RFCs and IETF drafts without leaving the terminal.
